# تطبيق «إسلام» — رَفِيقُكَ فِي تَدَبُّرِ كِتَابِ الله

تطبيق قرآني كامل مبني بـ **Flutter** — بلا إعلانات، Offline-First، بنية Clean Architecture
مع Riverpod. يشمل: قارئ مصحف (٦٠٤ صفحة)، استماع لأشهر المقرئين مع تكرار الآيات ومؤقت نوم،
بحث فوري بتطبيع عربي كامل، ختمة ذكية بإعادة توزيع تلقائية، إشارات وملاحظات وتمييز لوني،
مشاركة آيات كصور عالية الدقة، ولؤلؤة يومية.

---

## 1. التشغيل السريع

```bash
# 1) فعّل Flutter (الإصدار 3.22 أو أحدث):
flutter --version

# 2) انتقل لمجلد المشروع وثبّت الحزم:
cd islam_app
flutter pub get

# 3) شغّل التطبيق:
flutter run            # على جهاز متصل أو محاكي
flutter run -d chrome  # تجربة سريعة على الويب
```

> الخطوط العربية: التطبيق يعمل فوراً بالخط الافتراضي. لإضافة خط **Amiri**
> حمّله من fonts.google.com/specimen/Amiri وضع الملفات في `fonts/` ثم فعّل قسم
> `fonts:` في `pubspec.yaml` (موجود معلّقاً بالفعل).

## 4. خارطة الانتقال للإنتاج

1. **قاعدة البيانات:** استبدل `sample_data.dart` بـ Drift/Isar يضم ٦٢٣٦ آية + FTS5
   للبحث، وصور SVG لصفحات مصحف المدينة (رخصة مجمع الملك فهد).
2. **الخط العثماني:** أضف خط KFGQPC UTHMANIC HAFS (انظر `fonts/README.txt`).
3. **الصوت في الخلفية:** أضف `audio_service` — البنية جاهزة في `AudioNotifier`.
4. **المزامنة السحابية:** `POST /api/v1/sync` لرفع bookmarks/notes (JWT).
5. **الترجمات والتفاسير:** جلب متعدد اللغات عبر API مع تخزين محلي.

## 5. ملاحظات هامة

- صوتيات everyayah.com مجانية للاستخدام الشخصي — راجع شروطهم للنشر التجاري.
- التفسير المختصر معروض مختصراً للآيات المتوفرة؛ النسخة الكاملة تُحمَّل محلياً.
- الأداء: PageView مع بناء كسول، لا حاجة لتحسينات إضافية حتى على الأجهزة الضعيفة.
- اختبارات: `flutter test` (تطبيع عربي) — أضف اختبارات widgets تدريجياً.
- مجلد `design/`: أيقونة SVG جاهزة للتصدير 1024×1024 + نصوص المتجر الكاملة.

## 6. بناء APK تلقائياً — 3 نقرات فقط (بلا أوامر على جهازك)

> هذه البيئة بلا أدوات ترجمة، لذلك جهّزنا **بناءً سحابياً كاملاً**:

1. أنشئ حساباً مجانياً على [github.com](https://github.com) ← **Add new** ← **Upload files** ← اسحب مجلد `islam_app` كاملاً (أو ارفع `islam_app.zip` وافك ضغطه) ← **Commit**
2. افتح تبويب **Actions** ← اضغط **Build Islam APK** ← **Run workflow**
3. بعد ~7 دقائق افتح نفس التشغيل ← **Artifacts** ← حمّل `islam-app-apk` ← انسخ `app-release.apk` لهاتفك وثبّته ✅

السير (`.github/workflows/build_apk.yml`) يفعل كل شيء آلياً:
- `flutter create` لتوليد مشروع أندرويد
- **سحب كامل القرآن (6236 آية) وتفسير السعدي من api.quran.com الرسمي** مع تحقق عددي إلزامي
- حقن إذن الإنترنت في AndroidManifest
- توليد أيقونة التطبيق (`flutter_launcher_icons`)
- بناء APK + AAB ورفعهما كمخرجات قابلة للتحميل
